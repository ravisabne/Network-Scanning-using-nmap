# Network-Scanning-using-nmap
## introduction 
Nmap is an important tool in cybersecurity because it helps professionals monitor network security, troubleshoot network issues, and perform authorized security assessments In simple words: Nmap is a network scanning tool that helps us understand what devices are connected to a network and which ports and services are available on those devices.

## objective 
- Network Discovery: To identify active devices connected to a network.
- Port Scanning: To find open, closed, and filtered ports on a system.
- Service Detection: To identify services running on open ports.
- OS Detection: To determine the operating system of a target device.
- Security Auditing: To identify potential security weaknesses in a network.
